# 城市换电业务看板 · 静态发布版（CityBike）

> 「城市换电业务看板」的**单文件静态发布版**：`index.html` 自包含页面结构、样式与脚本，数据随页加载，直接双击本地打开或用任意静态服务器托管即可查看，**不需要后端、不需要登录**。

`原生 HTML / CSS / JS` · `ECharts（本地化）` · `GitHub Pages`

---

## 1. 与完整版的关系

| 版本 | 形态 | 说明 |
|------|------|------|
| 完整版 | Flask + 数据抽取构建管线 | 连接业务库只读抽取，覆盖用户、网点、设备、电池、财务、销售、运维等 10+ 业务模块，见仓库 `citybike-dashboard` |
| 本仓库 | 单文件静态快照 | 面向公网展示的轻量只读版本，无服务端依赖，打开即看 |

两者共用同一套前端视图与指标口径，差别只在数据来源：完整版实时连库，本仓库读取随页打包的静态数据。

## 2. 技术原理

- **单文件自包含**：页面结构、样式、脚本内联，减少静态托管下的路径与依赖问题，适合直接分发；
- **数据随页加载**：以本地 JSON 结构喂给前端渲染，页面发起的接口请求由内置的本地数据映射接管，不向任何外部服务发请求；
- **零外部依赖**：图表库等资源本地化，无外网 CDN 请求，内网与离线环境同样可打开；
- **免登录**：打开即进入看板主体，不再经过登录页，适合作为公网展示页。

## 3. 文件说明

```
citybike_pub/
├── index.html                  # 自包含看板页面（结构 + 样式 + 脚本 + 数据装配）
├── dashboard_data_lite.json    # 聚合后的轻量数据集，便于复用与二次加载
└── .nojekyll                   # 关闭 GitHub Pages 的 Jekyll 处理
```

## 4. 本地查看

直接双击 `index.html`，或在目录下起一个静态服务器：

```bash
python -m http.server 8000
# 打开 http://127.0.0.1:8000/
```

## 6. 数据与安全说明

- 数据为业务库**聚合后的脱敏快照**：手机号 / 证件号 / 姓名 / 商家名按掩码处理，明细列表置空或截断为样例；
- 库表名、内网 IP、外链图片地址已替换或移除；
- 页面为**纯静态只读**，不含任何写操作与账号体系。
